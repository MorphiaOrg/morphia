Mapper Benchmarks

Morphia ships two ways to map entities. These JMH benchmarks compare them on the same workload:

reflection

The default mapper. It discovers entity models through reflection at runtime.

critter

The critter mapper with models generated at build time by the critter-maven plugin.

critter-runtime

The critter mapper with models generated at runtime, which is the fallback when no build-time models are present.

Results come from the manually triggered Mapper Profiling workflow, which runs on shared GitHub-hosted machines. Absolute numbers shift from run to run, so compare the variants within a run rather than reading too much into a single value.
